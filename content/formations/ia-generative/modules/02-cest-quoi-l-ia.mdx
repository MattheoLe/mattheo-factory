<Slide kicker="Question à la salle">

# Où avez-vous croisé de l'IA aujourd'hui ?

<Points>

- Le **GPS** qui recalcule l'itinéraire selon le trafic
- Le **filtre anti-spam** de votre messagerie
- Les **suggestions** de vidéos, de séries, de musique
- Le **visage** qui déverrouille votre téléphone
- La **traduction** automatique d'une page web

</Points>

<Notes>

**Faire chercher la salle d'abord (2 min)**, puis révéler les exemples un par un.

Message : **vous utilisez déjà l'IA tous les jours, sans le savoir.** Elle n'est pas arrivée avec ChatGPT : elle est simplement devenue visible.

</Notes>

<Slide kicker="Définition">

# Un programme qui apprend à partir d'exemples

<Columns>
  <Card title="Programme classique">Un humain écrit toutes les règles : « si le mail contient tel mot, alors c'est un spam ».</Card>
  <Card title="Intelligence artificielle" step signal>On lui montre des millions d'exemples de spams et de vrais mails. Elle trouve seule les règles.</Card>
</Columns>

<Notes>

**L'idée clé de la séquence.** Une IA n'est pas un cerveau : c'est un programme qui **trouve des régularités** dans beaucoup d'exemples.

Image utile : apprendre à reconnaître un chat. On ne décrit pas « quatre pattes, des moustaches… », on montre des milliers de photos de chats.

</Notes>

</Slide>
</Level>

<Slide kicker="Les familles de l'IA">

# Des poupées russes

<Rings rings={[
  { label: "Intelligence artificielle", hint: "Tout programme qui imite une capacité humaine" },
  { label: "Machine learning", hint: "Apprentissage automatique : elle apprend à partir d'exemples" },
  { label: "Deep learning", hint: "Apprentissage profond : de très grands réseaux de neurones artificiels" },
  { label: "IA générative", hint: "Elle crée du contenu nouveau : texte, image, son, vidéo, code" },
  { label: "IA agentique", hint: "Elle agit : elle planifie, utilise des outils et enchaîne les tâches" }
]} />

<Notes>

Révéler les cercles un par un, de l'extérieur vers l'intérieur.

- On dit « IA » pour tout. Ce dont tout le monde parle depuis 2022, ce sont **les deux cercles du centre**.
- « Réseau de neurones » : simple inspiration biologique, ce n'est **pas** un cerveau.
- L'IA agentique n'est pas une technologie à part : ce sont des IA génératives **à qui on donne des outils** (navigateur, agenda, fichiers…) et un objectif. Simplification assumée.

</Notes>

</Slide>

<Slide kicker="La nouvelle étape">

# De la réponse… à l'action

<Pipeline highlight={4} steps={[
  { title: "Un objectif", text: "« Organise-moi un week-end à Lyon pour 2, budget 300 €. »" },
  { title: "Un plan", text: "Elle découpe la mission en étapes." },
  { title: "Des outils", text: "Elle cherche des trains, compare des hôtels, consulte la météo." },
  { title: "Une vérification", text: "Elle contrôle le budget, corrige si besoin." },
  { title: "Un résultat", text: "Un programme complet… à valider par vous." }
]} />

<Notes>

**L'IA agentique** : une IA générative ne fait que répondre ; un agent **agit** en plusieurs étapes, avec des outils.

Enjeu à souligner : plus on lui délègue d'actions (payer, envoyer, supprimer), plus **la validation humaine** devient importante. Lien avec le message clé : garder la main.

</Notes>

</Slide>

<Level is="decouverte">
<Slide kicker="La différence">

# Reconnaître… ou créer

<Columns>
  <Card title="IA « classique »">Elle **reconnaît**, trie, prédit. « Ce mail est un spam. » « Ce visage est le vôtre. »</Card>
  <Card title="IA générative" step signal>Elle **crée** quelque chose de nouveau : un texte, une image, une voix, une musique, du code.</Card>
</Columns>

<Notes>

Exemples d'IA génératives à citer : ChatGPT, Le Chat (Mistral, française), Gemini, Claude, Copilot pour le texte ; Midjourney ou DALL·E pour les images.

</Notes>
